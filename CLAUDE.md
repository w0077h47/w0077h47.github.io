## Project Overview

Personal website and portfolio for Andrew Niemann, built with Jekyll and hosted on GitHub Pages.

**Live URL:** https://w0077h47.github.io

## Tech Stack

- **Static Site Generator:** Jekyll (using GitHub Pages' built-in support)
- **Styling:** Custom CSS embedded in `_layouts/default.html` (no external CSS files)
- **Fonts:** Inter from Google Fonts
- **Hosting:** GitHub Pages (auto-deploys from `main` branch)

## Key Design Decisions

### Styling Approach
- All CSS is embedded in `_layouts/default.html` to minimize HTTP requests
- CSS variables used for theming (light/dark mode)
- No build tools or preprocessors - plain CSS

### Dark Mode
- Auto-detects system preference via `prefers-color-scheme`
- Manual toggle button in top-right corner
- Preference saved to `localStorage`

### Accessibility
- WCAG AA compliant color contrast
- Skip-to-content link for keyboard navigation
- `prefers-reduced-motion` respected for animations
- Focus-visible indicators for keyboard users
- Semantic HTML (`<main>`, `<header>`, `<section>`)

### Images
- Profile photo has all EXIF/PII metadata stripped
- Images stored in `assets/images/`

## Common Tasks

### Local Development
```bash
bundle install
bundle exec jekyll serve
# Visit http://localhost:4000
```

Note: Requires Ruby 3.0+ (GitHub Pages handles this automatically)

### Adding a New Page
1. Create `pagename.md` in root
2. Add frontmatter:
   ```yaml
   ---
   layout: default
   title: Page Title
   description: SEO description for this page.
   ---
   ```
3. Use HTML with CSS classes from `default.html` for styling

### Modifying Styles
- All CSS is in `_layouts/default.html` within `<style>` tags
- CSS variables are defined in `:root` and `[data-theme="dark"]`
- Test both light and dark modes after changes

### Adding Images
1. Strip metadata: `exiftool -all= image.jpg`
2. Place in `assets/images/`
3. Reference as `assets/images/filename.jpg` or `{{ '/assets/images/filename.jpg' | relative_url }}`

## CSS Class Reference

### Layout Classes
- `.header-card` - Blue gradient header section
- `.header-card.with-photo` - Header with profile photo (flex layout)
- `.section-card` - White/dark card container
- `.site-footer` - Footer section

### Content Classes
- `.summary-text` - Body text paragraphs
- `.skill-tags` / `.skill-tag` - Skill badges
- `.link-list` / `.link-item` - Styled link cards
- `.experience-item` - Timeline-style job entry
- `.education-item` - Education entry row
- `.built-with` - "Built with" pill badge

## Git Workflow

- `main` branch auto-deploys to GitHub Pages
- Create feature branches for changes: `feat/description`
- Commits should follow conventional commits format

## External Links

All external links should include:
```html
target="_blank" rel="noopener noreferrer"
```

- Open Graph and Twitter Card meta tags in layout
- Sitemap auto-generated by `jekyll-sitemap` plugin
- Canonical URLs set automatically
